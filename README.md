# Amor de mi vida - Railway

Version autocontenida: estilos, JavaScript, rosa y fotografias estan integrados dentro de `index.html`, por lo que no depende de rutas de archivos estaticos.

## Railway
1. Sube TODOS estos archivos a la raiz del repositorio.
2. Railway detectara Node.js.
3. Start command: `npm start`.
4. Genera un dominio en Networking.
