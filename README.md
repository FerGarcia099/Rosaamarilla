# Rosa Amarilla - Para Alison

Página romántica pensada para teléfono y escritorio.

Incluye:
- Rosa amarilla animada al inicio.
- Transición de rosa a pantalla completa al abrir la carta.
- Carta personalizada para Alison, firmada por Fernando.
- Pétalos amarillos cayendo de fondo.
- 10 fotografías personales con frases románticas.
- Frase final especial.

## Cómo abrirla
Abre `index.html` en Chrome, Edge, Safari o Firefox.

## Publicarla gratis
Puedes subir esta carpeta a GitHub Pages, Netlify o Cloudflare Pages y compartir el enlace.
